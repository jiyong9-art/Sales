# 에이원 영업 모바일 (시안)

회사 비밀번호로 잠근 영업 모바일 시안입니다. `app.enc`는 암호문이라 비밀번호 없이는 열 수 없고, `slot.json`은 그 열쇠를 비밀번호로 감싼 파일입니다. 시안의 고객·계약은 모두 가짜 데이터입니다.

- 주소: https://jiyong9-art.github.io/Sales/
- 아이폰: 사파리로 열고 공유 → '홈 화면에 추가' / 갤럭시: 크롬·삼성 인터넷 → '홈 화면에 추가'
- 업데이트: 같은 주소 그대로 — 다시 열면 새 판

## 이번 판 (v9)

**디자인**
- 머리: 에이원코리아 로고 + 검색 + 알림(종)·더보기 — 한 줄 정리
- 아래: 탭 바(할 일 · 만기 · 처리중 · 안내) + 가운데 **[＋ 오더 작성]** 알약 버튼, `safe-area-inset-bottom` 반영
- 목록·카드: 테두리 한 겹, 얇은 줄, 넉넉한 여백, 꼬리표는 바탕 칩으로(11.5px, 명도 대비 4.5:1 이상)
- 320px에서 날짜·금액이 붙지 않게, 다크모드 색 정리, 상세 시트는 내용만큼만 올라오게

**오더함 AI 음성 오더 바**
- 말로 채우기 / 통화 녹음 올리기 / 붙여넣기 → [채우기] (한 손으로 누르기 쉬운 3칸)
- 서버 연동 지점: `VOICE_API`(a1-voice-order `/api/sales/voice`) — 주소를 넣으면 서버가 전사+구조화(`SalesOrderDraft`)를 맡고 `applySalesDraft()`가 칸을 채웁니다. 지금은 폰 기본 인식 또는 시험용 GPT 키.

**고친 버그**
- 보낸 오더·고객·기록·일정을 이 폰에 저장(`localStorage` `a1sales-v9`) — 새로고침해도 유지. 초기화는 더보기 → 데모 자료 초기화.
- 고객을 고른 뒤 글자를 더 쳐도 고객 연결(`c: id` · `k: id`)이 끊기지 않음.
- 처리중 탭 배지 = 댓글 수가 아니라 실제 진행 중 건수.
- 중복 `case 'aiMic'` 등 죽은 분기와 더보기의 구버전 탭 설명 정리.
