# 에이원 영업 모바일 (시안)

회사 비밀번호로 잠근 영업 모바일 시안입니다. `app.enc`는 암호문이라 비밀번호 없이는 열 수 없고, `slot.json`은 그 열쇠를 비밀번호로 감싼 파일입니다. 시안의 고객·계약은 모두 가짜 데이터입니다.

- 주소: https://jiyong9-art.github.io/Sales/
- 아이폰: 사파리로 열고 공유 → '홈 화면에 추가' / 갤럭시: 크롬·삼성 인터넷 → '홈 화면에 추가'
- 업데이트: 같은 주소 그대로 — 다시 열면 새 판

## 이번 판 (v10)

**하단 가운데 = A1 로고 메인 버튼**
- 탭 바 가운데를 에이원 A1 심볼(흰 A, 남색 원 54px) 버튼으로 바꿈 — 탭 바 위로 살짝 돌출, 흰 테두리·그림자, 아래 작은 `오더` 라벨. 오더를 쓰던 중이면 점 표시.

**오더함 — 5종 행동 · 큰 보험사 칸 · 숨은 산출기초**
- 행동 5분할 컬러 세그먼트: 견적(파랑) · 계약(초록) · 배서(주황) · 해지(빨강) · 사고접수(보라). AI가 말·문자·서류에서 찾은 행동은 그 칸에 `AI` 표시와 함께 자동 선택.
- **보험사 칸은 오더 입력 화면에서 없앴습니다.** 말·문자·서류에서 AI가 찾은 보험사·구분(슬립/협정)은 아래 확인 단계에서만 보이고, 거기서 고칩니다(`삼성화재, 처브`→`삼성, 라이나` 자동완성).
- 오더 내용(말하기·음성·카톡 붙여넣기·메모) 칸을 화면의 30%부터 시작해 글 길이에 따라 절반까지 키움 — 한 화면에서 길게 보고 고침.
- 산출기초는 **평소 접힘**(`산출기초 3/5칸 — 직접 펼치기`), 원하면 그 자리에서 펼침.
- **[확인 및 전송]을 누르면 비교 화면**: 위에는 내가 쓴 원문(말·메모·붙인 서류)이 그대로 남고, 아래에서 서식 패널이 스르륵 떠오릅니다. 패널은 따로 스크롤되고 맨 아래에 **[업무팀 전송]**.
  - 그 행동·상품에 맞는 칸만 나오고(아래 표), AI가 채운 칸은 노랑 + `AI`, 아직 빈 필수 칸은 빨강 + `비어 있음`. 채우면 표시가 그 자리에서 바뀝니다.

**행동·상품별 산출기초 칸** (`PRODUCTS` 표 한 곳에서 관리)

| 행동 | 칸 |
| --- | --- |
| 견적 · 계약 | 상품별 산출기초 + 계약일·종기일·목적물 |
| 배서 | 기준일 · 변경 항목 (+ 상품별) |
| 해지 | 해지일 · 해지 사유 |
| 사고접수 | 사고 일시 · 사고 장소 · 사고 경위 → 접수번호(`A26-1118-001`) 자동 |

| 상품 | 칸 |
| --- | --- |
| 자동차 | 차량번호 · 차명·형식 · 연식 · (대인·대물 한도) |
| 화재 | 건물 구조 · 면적(㎡) · 가입금액(만원) |
| 배상(건설기계 영업배상) | 등록번호 · 기종 · (기계가액) |
| 근재(근로자재해) | 연간임금총액 · 인원수 · 보상한도 |
| 적하 | 인보이스(USD) · 출발지 · 도착지 · (담보 조건) |

**AI 연결 (`/api/sales/voice`)**
- 말로 채우기 · 녹음/서류 올리기(사업자등록증·차량등록증·신분증·청보) · 문자 붙여넣기 → 서버가 글자로 바꾸고 `draft`(오더 칸 + `basis` + `customer` + `missing`)를 돌려줌. 서버가 없거나 실패하면 폰 규칙(`parseMemo`)으로 넘어감.
- 요청: `multipart/form-data` — `audio`(녹음) · `text`(문자·메모) · `image`(서류 사진, 여러 장) + `context`. 머리말 `x-a1-passcode`.
- 비밀번호는 소스에 넣지 않습니다. **잠금 화면에서 넣은 값을 그 탭의 `sessionStorage`(`a1-sales-pass`)에만** 두었다가 머리말로 보내고, 없으면 한 번 물어봅니다(메모리에만). ‘다음부터 묻지 않기’로 열어 비밀번호가 없으면 그때 한 번 묻습니다.
- 서류에서 읽은 고객이 명부에 없으면 확인 영역에 **[＋ 고객명부에 등록]** — 사업자번호·대표·주소·전화가 그대로 들어가고 오더 대상이 됨.
- **[업무팀 전송] 때 남는 것**: 채워진 서식 값 + 원래 오더 원문(양식에 안 들어간 남은 메모·음성 원문) + 붙인 서류 이미지가 모두 `REQ`(`form.vals` · `form.memo` · `form.attachments`)에 저장되고, 업무팀 상세(처리중 → 그 오더)에서 ① 오더 내용 ② 원문 ③ 붙인 서류를 한 화면에 봅니다.

**검색**
- 안내 문구: `고객명 · 주민번호 · 사업자번호 · 증권번호 · 사고접수번호`
- 고객명, 주민번호(생년월일 앞 6자리 또는 13자리), 사업자번호, 휴대폰, 증권번호·차량번호, 사고접수번호로 찾음. 증권번호를 정확히 치면 그 계약이 바로 열림.

**그 밖**
- 보낸 오더·고객·기록·일정은 이 폰에 저장(`localStorage` `a1sales-v9`). 초기화는 더보기 → 데모 자료 초기화.
- 320px에서는 확인 영역 칸이 위아래로 쌓여 날짜·금액이 잘리지 않음. 다크모드 확인 영역 색 정리.

## 빌드

평문 HTML은 저장소에 올리지 않습니다(`.gitignore`).

```
A1PW='회사 비밀번호' python3 build.py 시안.html
```

작업용 평문은 저장소 밖(`work/sales-build/`)에서 만들고, 푸시 전에 지웁니다.
